# Student Grade Calculator

A simple Student Grade Calculator built with **HTML, CSS, and JavaScript**.

## Features

* Enter student name
* Enter marks for 5 subjects
* Calculate total marks
* Calculate percentage
* Calculate grade
* Check Pass/Fail
* Display result on the webpage

## Subjects

* English
* Math
* Science
* Computer
* Management

## Grading System

| Percentage | Grade |
| ---------- | ----- |
| 80+        | A     |
| 70+        | B     |
| 60+        | C     |
| 50+        | D     |
| 40+        | E     |
| Below 40   | Fail  |

## How to Run

Open `index.html` in **Chrome or Firefox**.

```bash
xdg-open index.html
```

Do not use:

```bash
node gradecalculator.js
```

because this project uses browser DOM features.
